# Political Duel V16

瀏覽器版卡牌對戰遊戲。

## GitHub Pages

1. 將 `index.html` 上傳到 GitHub repository 的根目錄。
2. 到 **Settings → Pages**。
3. Source 選擇 **Deploy from a branch**。
4. 選擇 `main` branch / `/ (root)`。
5. 儲存後等待 GitHub Pages 部署。

## 目前版本

- 玩家初始 LP：2000
- 角色 HP：1000
- 手牌上限：3
- 牌堆內容不公開
- 長按卡牌 2 秒：放大查看技能
- 滑鼠移過去不會自動放大
- 支援 AI 對戰
- 支援 PeerJS 雙人房間
- 技能動畫與攻擊特效
- 卡牌圖片已嵌入 `index.html`，不需要另外上傳 cards 資料夾

> PeerJS 連線功能需要瀏覽器能連線到網路。
