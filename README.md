# Alarm.com Sr. Mechanical Engineer Portfolio Mock Interview

GitHub Pages-ready English speaking practice website based on the uploaded portfolio.

### Added
- American-English question playback
- Browser speech recognition
- 30+ portfolio-specific interview questions
- Random interview mode and topic filters
- Local AI-style coaching score: Grammar, Fluency, Technical, Senior Level, Structure
- Adaptive follow-up questions based on the answer
- No backend and no API key required

### GitHub Pages
Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
Then: **Settings → Pages → Deploy from a branch → main → / (root) → Save**

Google Chrome is recommended for microphone speech recognition.
